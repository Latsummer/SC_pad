# 数据目录与保留策略

| 目录 | 内容 | 是否部署 |
| --- | --- | --- |
| `imports/scmdb/` | 用户从公开页面导出的原始蓝图、任务快照及来源 manifest | 否 |
| `imports/localization/` | 按补丁归档的原始汉化文件、社区语言表及哈希 | 否 |
| `data/` | 规范矿物／蓝图／任务数据、翻译表、审核覆盖与检查报告 | 否 |
| `capture-tools/` | 自动生成的书签安装页 | 否 |
| `dist/` | 实际发布的静态页面与浏览器数据 | 是 |

任务页面只加载列表索引；打开详情时才读取对应分片。`dist/missions/` 包含当前索引、32 个带内容哈希的详情分片，以及蓝图产出任务反向索引。构建自动移除旧详情分片，原始历史快照继续保留，不能拿“删除旧分片”代表“游戏任务移除”。蓝图反向索引不包含原始抓取文件或完整汉化文件。

规范任务文件与网页分片有意分别保留：前者用于审计和版本比较，后者用于按需加载。生成文件不得手工编辑；数据变化必须重新构建并通过一致性检查。差异报告的 changed 也包括翻译、结构化字段等变化，不一定是游戏修改。

缓存（`.sync-cache/`、`__pycache__/`、EdgeOne 状态）不提交，采集调试文件、截图和临时小批量导出不放进发布目录。历史归档不按时间自动删除，需要确认不再用于追溯后单独决定。
