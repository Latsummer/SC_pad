# 蓝图制造品质属性采样

原始导出单独存放于此，格式 `scmdb-public-fabricator-details-v1`。不要放入旧版 `scmdb-public-fabricator-*.json` 列表快照中，也不要用旧导入器覆盖现有配方库。

更新书签后在 SCMDB 原版英文 Fabricator 中打开详情，保持 Craft 视图，在“更多工具”中点“仅采当前蓝图”，等待完成与品质值恢复提示，然后点“导出 JSON”。首次选一个无品质加成的弹匣、一件武器、一件护甲。需要核对其他品质时调整公开控件，再点“记录当前快照”。

```sh
python3 tools/inspect_blueprint_details.py /path/to/scmdb-blueprint-details-....json --output /tmp/blueprint-quality-report.json
```

采集项包括：公开 recipe_id 与 URL、页面版本文本、成品属性原文与显示数值、护甲抗性、槽位与材料用量、品质输入范围／值、各影响项倍率端点和基础品质、四组预设观察结果。没有品质加成的配方保存页面明确说明；未知布局／模式不采。不会修改购物单、比较列表，不点击拆解。

点击“自动采集详情”启动批量采集，默认 10 个，详情页启动会先返回列表；只处理启动时已加载卡片，完成后返回列表。每个蓝图和批次结束保存到当前浏览器 IndexedDB；按可见游戏版本、翻译 URL、页面语言和频道隔离。刷新后先启动新版助手，再恢复进度；完成项跳过，失败项可重试。停止会等待当前蓝图采样和品质恢复结束。保存失败会显示提示，必须手动导出；默认批次结束自动导出 JSON（包含已记录列表卡片和属性样本），下载被拦截时请手动导出。辅助单项操作在“更多工具”内。浏览器冻结或电脑休眠会暂停。当前 Inspector 做身份与快照一致性校验、解析品质范围，不声称最终成品计算已验证。详情 DOM 缺少精确内部值时保留显示精度，不把显示舍入结果当成原始参数。

助手在列表页启动后立即记录已渲染卡片，详情作为后续补充；统一 JSON 导出包含两者。总体状态显示当前已加载列表数量、按卡片文字去重的记录数和详情完成数，不以当前列表数量声称全站覆盖。状态分总体、本批、当前蓝图／预设三行，预设切换不覆盖批次进度。卡片记录也随检查点保存和恢复。

“导入 JSON”支持本格式与旧版 `scmdb-public-fabricator-capture-v1` 卡片文件。先验证整份文件再合并，不删除已有记录；重复导入以配方 ID 去重，完整记录优先。新版导出包含 `card_recipe_links`，续采可直接跳过完成项；旧版没有映射时，先打开详情确认配方 ID，再跳过已有完整采样。文件版本缺失默认视为待重采；手动确认同版本可勾选后重导。明确版本、频道或翻译来源不匹配拒绝导入，跨版本更新应使用新会话。

可选自动分类范围会清除页面原有搜索／筛选，按公开筛选逐级分到优先不超过 100 个的列表；更小的组直接采。不能继续细分的较大组照常采集并提示。`本批蓝图数` 为所有分组本次合计上限。分组日志在 `grouped_runs`，详情批次日志仍在 `automation_runs`。停止后重启会重新分组，跳过已完成配方；旧无映射导出仍需打开一次确认身份。该模式不保证后台冻结时运行，不自动翻页。
